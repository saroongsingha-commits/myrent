# CHANGELOG.MD

Penjelasan singkat: file ini berisi **riwayat perubahan penting** proyek Ryokourent
App. Digunakan untuk audit lintas sesi — tidak seperti `SESSION_STATE.MD` yang
mencatat status pengerjaan *sesi ini*, `CHANGELOG.MD` tercatat *per perubahan
implementasi* (dikelompokkan berdasarkan rilis/versi).

Format ringkas:
- `## [versi] — tanggal`
- `### Ditambahkan` / `### Diperbaiki` / `### Dihapus`
- `### N/A` untuk perubahan yang sengaja tidak dilakukan.
